## Интерактивные дашборды DataLens

### 2026, Продуктовые и маркетинговые метрики

Подготовка датасета банковского приложения → расчёт продуктовых и маркетинговых метрик → сравнение каналов привлечения → визуализация динамики показателей → интерактивная фильтрация и интерпретация эффективности каналов.

**Стек:** Yandex DataLens

- [Ссылка на дашборд с анализом показателей](https://datalens.yandex/hvkzxbmjwt3q1?_share_link=public)

- **Задачи:**
  - Подготовка датасета: проверка типов данных и создание вычисляемых полей.
  - Расчёт ключевых метрик: регистрации (Regs), затраты (Cost), выручка (Revenue), стоимость привлечения клиента (CAC), эффективность рекламного канала (ROAS), отток пользователей (Churn Rate), средний LTV на пользователя, прибыль (Profit), окупаемость маркетинговых вложений (ROMI).
  - Создание дашборда с таблицей основных продуктовых и маркетинговых показателей в разрезе каналов привлечения.
  - Построение графиков динамики регистраций и затрат по каналам привлечения в разрезе месяцев.
  - Настройка интерактивных селекторов для фильтрации данных по дате регистрации и каналу привлечения.
  - Анализ полученных показателей, сравнение эффективности каналов и формулирование рекомендаций по масштабированию или отключению каналов привлечения.
